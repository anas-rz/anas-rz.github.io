# Oil Debris Monitoring System using Deep Learning

This project presents an **intelligent oil debris monitoring system** designed for **predictive and preventive maintenance of mechanical systems**. It was developed as an undergraduate engineering project at **UET Taxila**, where a multidisciplinary team of five members designed and implemented a sensor-based anomaly detection pipeline.

---

## Overview

Mechanical systems such as engines and industrial machinery rely heavily on lubrication health. Early detection of wear particles in oil can prevent catastrophic failures.

This system combines:

* A fabricated oil debris sensor hardware prototype
* Time-series data acquisition pipeline
* Deep learning-based anomaly detection models
* Real-time reporting of abnormal lubrication patterns

---

## System Design

The system consists of:

### 1. Sensor Layer

* Custom-built oil debris sensing hardware
* Continuous monitoring of lubricant condition

### 2. Data Acquisition

* Time-series collection of sensor readings
* Preprocessing and noise filtering

### 3. Deep Learning Module

* Anomaly detection model trained on temporal patterns
* Detection of deviations from normal lubrication behavior

### 4. Alert System

* Reporting of abnormal conditions
* Designed for preventive maintenance decisions

---

## Machine Learning Approach

The system leverages **time-series anomaly detection techniques**, enabling it to:

* Learn normal operating patterns of lubricants
* Detect deviations indicating mechanical wear
* Trigger early warnings for maintenance
